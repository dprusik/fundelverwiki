Jawna decyzja dla zaznaczonych plików

Poniższe przyciski zapisują decyzje tylko dla plików zaznaczonych na liście. Dla notatki z załącznikami użyj wspólnego przeglądu w jej podglądzie lub przycisku nad listą. Każdy plik zachowuje osobną zgodę. Nieznane lub brakujące zależności nadal blokują publikację.

Propozycja i świadomy import

Najpierw zapisz decyzje przyciskiem „Zatwierdź zaznaczone po przeglądzie” i sprawdź potwierdzenie zapisu. Samo zaznaczenie plików i pola potwierdzenia nie zapisuje zgód.

Eksport tworzy nową lokalną propozycję. Nie nadpisuje src/wiki ani plików źródłowych. W terminalu repozytorium uruchom npm run publication:import -- preview "ścieżka-do-propozycji.json". Po sprawdzeniu diffu użyj apply "ścieżka-do-propozycji.json" --confirm IDENTYFIKATOR-DIFFU zamiast preview. Stan aktywnych zgód: npm run publication:status. Import nie odblokowuje produkcyjnego buildu.
